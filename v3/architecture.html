reMarkable Paper Pro / Version 3.0

From a published image to the paper screen

The AppLoad application adds an immediate preview and manual download to the existing v2 publishing and update pipeline.

One image, two ways to refresh

The timer and AppLoad share the same updater, configuration and lock. Refresh checks the latest published image; it does not start GitHub generation. The app watches the installed file for timer updates.

Device-specific risks

AppLoad has an unresolved close/disconnect crash risk. A root read-only remount failure was observed after an update. The changed-image manual download still needs on-device verification. See AppLoad setup and recovery.
